Customer Churn Prediction using ANN

This project predicts customer churn using an Artificial Neural Network built with TensorFlow and Keras. The model was optimized using GridSearchCV (SciKeras) and deployed as an interactive web application using Streamlit.

Tech Stack

Python, Pandas, Scikit-learn, TensorFlow, Keras, SciKeras, Streamlit

Workflow

Data preprocessing (dropping unnecessary columns, encoding categorical features, feature scaling)

ANN model building and training

Hyperparameter tuning using GridSearchCV

Model deployment using Streamlit

This project demonstrates an end-to-end machine learning pipeline from preprocessing to deployment.
